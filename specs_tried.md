| 11 | 2026-11-11 | Charlie | Scoring access: Expected Parrot | Team has Expected Parrot (EDSL) keys, not OpenAI keys, so `tariff_batch.py` gains `--backend parrot`. Difference: OpenAI's strict JSON schema cannot be enforced through EDSL, so the prompt adds one line asking for JSON only; a reply that is not valid JSON is logged as a failure, never repaired or guessed. Checked with EDSL 1.0.9's offline test model: the prompt sent is exactly our instructions + filing, no system prompt added. EDSL needs Python 3.10-3.13. Model not yet chosen. |
